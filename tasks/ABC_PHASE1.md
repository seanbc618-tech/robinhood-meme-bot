## 共同入场与预算
安全筛选：毕业 phase2、有可用流动性、支持 native ETH/USDG、持有人>=15、前10流通持有占比<=60%（沿用现有剔除定义并报告）；往返 eth_simulateV1 必须成功，失败不得入场。不支持状态覆盖的 USDG 不伪造通过。
A/B 交易本金<=30USD，C<=15USD；费用另外计入成本但每次总现金支出<=35/20；每套最多5个仓位，不补仓、不杠杆、不重新买同一币（一期避免反复磨损）。现金保留200；所有账户各自累计净值<=200永久停止新买，继续尝试真实可报价退出。日亏损含浮亏：UTC日开始可用净值为基准，跌30停止该日新买；如果跨日估值未知，先禁止入场，恢复后使用可核验的日基准，不重置既有亏损。写明具体基准规则。
预计完整往返成本<=5%：按计划实际金额 buy quote -> haircut后的数量 -> sell quote，再扣两腿 modeled gas 与 L1 allowance，比最初完整成本算损失，禁止仅用 SDK fee 或 eth_simulate 不含gas的损失。现有买卖各3% haircut本身超过5%门槛，所以 ABC 首轮冻结为每腿额外0.5% haircut（独立于 quoter 内含费用/价格冲击），沿用gas+L1 allowance并诚实标记模型；压力比较至少每腿1.5%与3%，不能为凑成交降低门槛。没有满足条件的交易是合法结果。原策略模型不变。
按 BigInt 管理 token qty；净值从可退出的整仓报价扣费形成，不按边际价格乘数量充当变现价值。原始成本不随部分卖出改写。止损无法报价则保留持仓、估值null、记退出未完成，不能造止损价成交。持仓价未知时整个账户 equity=null，并冻结新买。

## 冻结策略定义
用完整分钟桶 t，所有此前窗口排除 t。p为桶收盘价；每个信号/阶段持久化防重启丢失。
A 突破回踩：毕业>=2h。L=此前30个完整分钟最高价；t收盘>L*1.005则建立突破状态，冻结L和突破时间。之后1~15分钟出现最低价落入[L*0.98,L*1.02]且收盘>=L，确认回踩；收盘<L*0.98则失效。随后1~10分钟收盘高于回踩确认桶最高价，最近5分钟外部净流入>0且买入接收地址数高于此前5分钟且>=8，生成一次信号。过期重新等待新突破。
B 成熟趋势：毕业>=24h、完整至少120分钟。最近60分钟收盘简单均价>之前60分钟均价，收盘>此前60分钟最高价*1.005，最近15分钟USD成交额>此前4个不重叠15分钟窗口平均的1.5倍，最近15分钟净流入>0，买入接收地址>=8。一次突破只产生一次信号。
C 第二波：毕业>=30min且<=6h，有连续至少30分钟有效桶。观察到相对先前低点上涨>=30%后固定第一波峰值（后续更高峰可更新，回调确认后不再使用未来最高点）。从峰回调15%~30%建立回调阶段，低于峰70%作废；至少3根回调桶后，最近3分钟卖出额低于此前3分钟、最近3分钟净流入>0，收盘突破此前3根回调桶最高价触发；窗口无法完整比较则等待。买入接收地址>=8、任一接收地址占最近5分钟买量<=25%；这只是可观测集中度，不声称识别关联钱包。

## 退出（优先级：账户熔断、止损、超时、止盈/追踪）
以当前净整仓退出价值/剩余数量折算到初始数量，除以初始含费成本为收益倍数；token数量换算注意精度。追踪峰值用同样每token净值口径，部分卖出不得导致人为回撤。执行部分卖出必须重新按实际数量报价。
A -12%全出；+25%卖初始数量一半仅一次；剩余仓从确认的峰值跌12%全出（部分止盈之后启用）；开仓60分钟内从未达到+10%，到期全出。
B -15%全出；+40%卖初始数量一半仅一次；之后从峰值跌18%全出；开仓6小时全出。
C -20%全出（回本前）；2倍卖足数量覆盖初始完整成本减已回收净额（二分报价核实，不能按比例粗算）；回本后取消固定止损以满足尾仓偏好，10倍卖剩余一半仅一次。开仓2小时内从未达到+10%且未回本则全出；回本后尾仓无时间止损，仍受账户熔断。明确这种尾仓会回吐盈利。
